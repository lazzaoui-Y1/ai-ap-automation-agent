RÈGLES CRITIQUES :
═══════════════════════════════════════════════════

1. Extraire TOUS les champs disponibles du texte
2. Champs REQUIS :
   - invoice_number (Numéro de facture)
   - invoice_date (Date de facture)
   - vendor.name (Nom du fournisseur)
   - line_items (Articles - au moins un)
   - subtotal (Sous-total)
   - total_amount (Montant total)

3. Format de date : YYYY-MM-DD (exemple : 2024-02-07)

4. Nombres :
   - Utiliser des nombres réels, pas des chaînes (100.50, pas "100.50")
   - Pas de symboles de devise dans les nombres
   - Point pour décimales (100.50, pas 100,50)

5. Calculs :
   - Vérifier line_total pour chaque article : (quantity × unit_price) - discount + tax_amount
   - Vérifier total_amount : subtotal - total_discount + total_tax

6. Numéro de TVA français :
   - Format : FR + 11 chiffres (exemple : FR12345678901)
   - SIREN/SIRET : 9 ou 14 chiffres

7. Codes de devise (ISO 4217) :
   - Euro → EUR
   - Dollar → USD
   - Livre → GBP

8. Taux de TVA en France :
   - Taux normal : 20%
   - Taux réduit : 10%
   - Taux super-réduit : 5.5%
   - Taux particulier : 2.1%

9. Si une information n'est pas trouvée, utiliser null (ne pas inventer de données)

10. **CRITIQUE** : Retourner UNIQUEMENT du JSON valide, sans explications ni blocs de code markdown
